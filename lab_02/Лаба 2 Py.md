**Теоретические сведения**
  
**Условный оператор if-elif-else:** Используется для проверки логических условий и ветвления алгоритма. Конструкция elif позволяет связывать несколько последовательных проверок без добавления лишней вложенности отступов. Блок else выполняется, если ни одно из условий не

  
подтвердилось. Обязательным синтаксическим правилом является использование двоеточия (:) и строгое соблюдение отступов (4 пробела).

  
**Цикл while:** Выполняет блок выражений до тех пор, пока проверяемое условие истинно (True). Для экстренного выхода из цикла применяется оператор break, а для перехода к следующей итерации — continue. При естественном завершении цикла выполняются команды из необязательного блока else.

  
**Цикл for..in и функция range():** Осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция range(start, stop, step) генерирует арифметическую прогрессию чисел, не включая верхнюю границу stop.

  
**Пользовательские функции (def):** Представляют собой многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова def, принимает параметры и возвращает результаты вычислений оператором return. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции для описания ее назначения.

  
**Индивидуальное задание и его выполнение**
  
**Суть задания:** Написать функцию analyze\_power\_quality(u\_list),

  
подсчитывающую в цикле число провалов (U < 207 В) и

  
перенапряжений (U > 253 В). Функция возвращает булев флаг

  
соответствия ГОСТ (отклонения < 5% от общего числа замеров).

  
**Код выполненного задания и пояснения к нему:**
  
def analyze\_power\_quality(u\_list):  
lowV = 0  
highV = 0

  
for u in u\_list:  
if u < 207:  
lowV += 1  
elif u > 253:  
highV += 1  
  
deviations = lowV + highV  
total = len(u\_list)  
  
return deviations / total < 0.05  
  
u\_list = \[220, 205, 230, 260\]  
print(analyze\_power\_quality(u\_list))

  
u\_list – взятые для анализа показатели напряжения

  
lowV - счётчик провалов напряжения
  
highV - счётчик перенапряжений
  
deviations – общее количество отклонений напряжения

  
total – общее количество показателей напряжения
  
deviations / total < 0.05 – проверка, отклонений меньше 5% среди взятых измерений или нет

  
return – возвращает True/False
